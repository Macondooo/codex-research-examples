# Repository instructions

Use the project skill `$mnist-live-demo`. Read `TASK.md`, `REQUEST.md`, `data/README.md`, and `expected/README.md` before making changes.

Do not modify `data/raw/` or the project brief files. Put reusable Python code in `src/`, tests in `tests/`, and experiment artifacts in `outputs/`. Keep the dependency file and `REPORT.md` at the project root.

Implement only the model and outputs required by `TASK.md`. Do not add alternative models, tuning, notebooks, user interfaces, or unrelated infrastructure.

Before finishing, run the tests and full experiment and inspect both figures. Then ask the `work-review` subagent for a read-only review. If it reports a correctness or reproducibility issue, fix it and rerun the affected checks. In the final response, list the exact commands run and the measured metrics.
