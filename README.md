# Codex 科研工作流示例

## 目录

```text
code_data_text_analysis/
├── data_analysis/          # 数据分析练习
├── data_analysis_ready/    # 数据分析完成示例
├── text_analysis/          # 文本处理练习
└── text_analysis_ready/    # 文本处理完成示例

worker_reviewer/
├── worker_reviewer_demo/      # Worker / Reviewer 协作流程模板
└── worker_reviewer_demo_run/  # Worker 已执行的 Iris KNN 示例
```

不带 `_ready` 的目录为实操模板，带 `_ready` 的目录为已完成并运行验证的示例。

`worker_reviewer_demo` 为 Worker / Reviewer 协作流程模板，`worker_reviewer_demo_run` 为已运行的完成示例。
