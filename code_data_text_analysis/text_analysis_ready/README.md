# Tokenizer and Word-Frequency Exercise

This directory contains a self-contained Codex exercise in deterministic tokenization and corpus-level word-frequency analysis. The assignment, implementation request, and input data are fixed for reproduction.

## Reproduction procedure

1. Copy the complete directory to a machine with Codex and Python available.
2. Open the copied directory as the Codex workspace.
3. Submit the following instruction:

   > Complete `TASK.md` in accordance with `AGENTS.md` and the constraints recorded in `REQUEST.md`. Run the required verification and report the commands, results, and generated artifacts.

4. Review the tests, generated files, and `REPORT.md` against `expected/README.md`.

Codex loads the repository requirements in `AGENTS.md`. Modify the completed `REQUEST.md` only when different implementation requirements are needed. The supplied assignment, data, and reference result are immutable.
