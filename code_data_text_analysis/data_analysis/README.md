# Life Expectancy Regression

This directory is a Codex workspace for a reproducible data analysis exercise. The dataset and project requirements are provided. Each student completes the request template before submitting the task to Codex.

## Exercise procedure

1. Read `TASK.md` and `data/README.md`.
2. Complete `REQUEST.md` with the required outcome, additional constraints, and acceptance criteria.
3. Open this directory as the Codex workspace and submit: `Complete TASK.md in accordance with AGENTS.md and the additional constraints recorded in REQUEST.md. Run the required verification before reporting completion.`
4. After execution, evaluate the repository against `expected/README.md`.

Codex loads `AGENTS.md` as the repository instructions. The supplied task, dataset, data card, and expected-result reference are immutable during the exercise.

## Supplied structure

```text
.
├── AGENTS.md          # persistent repository guidance for Codex
├── README.md          # exercise instructions
├── REQUEST.md         # student-written request
├── TASK.md            # fixed project contract
├── .gitignore         # local Python artifacts
├── data/
│   ├── README.md      # data card
│   └── life_expectancy.csv
└── expected/
    └── README.md      # completion reference
```

Implementation files and generated outputs are intentionally absent from the starter workspace and must be created during the exercise.
