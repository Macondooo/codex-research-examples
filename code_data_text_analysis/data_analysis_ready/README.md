# Life Expectancy Regression

This directory is a prepared Codex workspace for reproducing the data analysis exercise. The project task, completed request, and dataset are provided.

## Reproduction procedure

1. Copy the complete directory to a machine with Codex and Python available.
2. Open the copied directory as the Codex workspace.
3. Submit: `Complete TASK.md in accordance with AGENTS.md and the additional constraints recorded in REQUEST.md. Run the required verification before reporting completion.`
4. Evaluate the tests, generated outputs, and `REPORT.md` against `expected/README.md`.

Codex loads `AGENTS.md` as the repository instructions. Modify the completed `REQUEST.md` only when alternative constraints are required. The supplied task, dataset, data card, and expected-result reference are immutable.

## Supplied structure

```text
.
├── AGENTS.md          # persistent repository guidance for Codex
├── README.md          # exercise instructions
├── REQUEST.md         # completed run request
├── TASK.md            # fixed project contract
├── .gitignore         # local Python artifacts
├── data/
│   ├── README.md      # data card
│   └── life_expectancy.csv
└── expected/
    └── README.md      # completion reference
```

Implementation files and generated outputs are intentionally absent from the prepared workspace and must be created during reproduction.
