# Tokenizer and Word-Frequency Exercise

This directory defines a self-contained exercise in deterministic tokenization and corpus-level word-frequency analysis. The assignment and input data are fixed. `REQUEST.md` records the implementation request submitted to Codex.

## Exercise procedure

1. Review `TASK.md`, `data/README.md`, and `expected/README.md`.
2. Complete `REQUEST.md`. State only requirements not already defined by the assignment.
3. Open this directory as the Codex workspace and submit the following instruction:

   > Complete `TASK.md` in accordance with `AGENTS.md` and the constraints recorded in `REQUEST.md`. Run the required verification and report the commands, results, and generated artifacts.

4. Review the tests, generated files, and `REPORT.md` against `expected/README.md`.

Codex loads the repository requirements in `AGENTS.md`. The supplied assignment, data, and reference result must remain unchanged.
